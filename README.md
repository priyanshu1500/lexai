# LexAI - Autonomous Legal AI Platform

LexAI is an autonomous legal AI system designed for legal practitioners in India. It automates legal research, document retrieval, verification, case tracking, and key note synthesis.

## Core Features & Vision

1. **Phase 1: SCC Judgments Scraper & CLI**
   - Automated CLI tool to search and download official judgment PDFs from SCC Online.
2. **Phase 2: Multi-Portal Citation Verification Engine**
   - Extract citation / reference numbers from downloaded judgments.
   - Fetch the identical judgment from official government e-Courts, High Courts, Supreme Court, MCA, ED, SBI, CCI, RBI, SFIO, and SEBI portals.
   - Run diff & verification algorithms to ensure integrity and exact matching between SCC copies and government records.
3. **Phase 3: Autonomous Government Portal Legal Agent**
   - Direct, unassisted retrieval from government legal & regulatory web portals without reliance on SCC.
   - Natural language prompt interface and UI button triggers for automated document fetching across tribunals and courts.
4. **Phase 4: Lawyer Personal Workspace & Case Automation**
   - Lawyer calendar with live status updates of ongoing cases.
   - Daily and next-day live hearing updates scraped from official court cause lists.
   - Automated synthesis of daily Key Case Notes and automated email notifications to attorneys.
